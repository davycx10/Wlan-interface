# Wlan-interface
project wlan show interface in multilanguage


Le projet sert surtout de support d'apprentissage : l'objectif est de développer le même petit programme dans plusieurs langages afin de découvrir leurs syntaxes, leurs outils et leurs particularités.

Langages

Le projet sera progressivement réalisé en :

Python
Rust
C
C++
Java

D'autres langages pourront éventuellement être ajoutés par la suite.

Informations affichées

Le programme pourra notamment afficher :

Système d'exploitation
Version du kernel
Nom de la machine
Processeur
Mémoire RAM
Stockage
Informations Wi-Fi

Le projet restera volontairement simple. Le but n'est pas de créer un outil professionnel de monitoring, mais d'avoir un petit projet concret permettant d'apprendre plusieurs langages.

Organisation

Chaque langage possède sa propre implémentation du programme.

pc-info/
├── README.md
├── python/
├── rust/
├── c/
├── cpp/
├── javascript/
├── typescript/
└── java/


Chaque version doit essayer de fournir globalement les mêmes informations, tout en utilisant les possibilités et les conventions du langage concerné.

Objectif

L'objectif principal est d'apprendre en pratiquant :

la syntaxe de différents langages ;
les types et structures de données ;
les fonctions et modules ;
la gestion des erreurs ;
l'utilisation des bibliothèques ;
la compilation et l'exécution des programmes ;
les différences entre langages de haut et de bas niveau.
Plateforme

Le développement est réalisé principalement sous Linux.

État du projet

Le projet est actuellement en développement.

La première version sera réalisée en Python, puis progressivement réimplémentée dans les autres langages.
